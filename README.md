# Galileo Thermometer Simulation

A beautiful, interactive web simulation of the classic Galileo thermometer.

## How to use

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).
2. Drag the temperature slider to watch the colored glass spheres rise and fall.
3. Read the short explanation on the right about how the instrument works and a bit of its history.

No build step or server required — it works offline as static files.

## Features

- Smooth animated spheres that float or sink according to temperature
- Gold temperature tags that highlight the closest reading
- Soft ambient lighting and subtle bubbles
- Responsive layout for desktop and mobile
- Accessible slider with live value display

Enjoy!
